# P1-04 — Prepare: зависимости целевой ОС без запуска приложений

**Статус:** READY (P1-01 принята 2026-09-23). **Поток:** подготовка ОС.
**Владелец:** `restore/prepare.py`, `restore/platforms/`,
`tests/unit/test_restore_prepare.py`.

- Реализовать только выбранные адаптеры установки Docker Engine/Compose и
  Certbot с зависимостями и запуском Docker. Существующую подходящую установку
  не переустанавливать и не обновлять без причины.
- До и после установки проверять identity/предусловия; все операции и
  результаты отдавать journal-интерфейсу. Package/registry errors ограничены
  по времени и диагностике, секреты не попадают в argv/логи.
- Предотвращать преждевременный запуск renewal при установке Certbot, включая
  действия package scripts; не трогать чужую автоматизацию и не устанавливать UFW.
- **Решение P1-01 (2026-09-23):** поддерживается только Ubuntu 24.04 x86_64;
  остальные ОС — `E_UNSUPPORTED`. Установка заблокирована (`install_confirmed: false`),
  пока installer не проверен на Linux (P1-15).
- **Готово:** prepare оставляет приложения и renewal выключенными; повтор
  не дублирует установку; протестированы supported/unsupported ОС, готовая
  установка, package failure и попытка ранней активации timer/service.
