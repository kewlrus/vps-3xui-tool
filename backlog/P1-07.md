# P1-07 — Digest images, Compose create и Fail2ban до первого старта

**Статус:** READY (P1-01 принята 2026-09-23). **Поток:** контейнеры.
**Владелец:** `restore/containers.py`, `tests/unit/test_restore_containers.py`.

- Скачать только полные `repository@sha256` с проверкой платформы и фактического
  digest. Недоступность registry/digest даёт отказ без fallback на mutable tag.
- Сохранить Compose project names, paths и digest overrides. Для panel реально
  установить cwd и PWD `/root/panel`; проверить фактические mounts созданных
  контейнеров, а не только `compose config --quiet`.
- Создать включённые контейнеры остановленными. Восстановить `/etc/fail2ban` и
  `/var/lib/fail2ban` в writable layer panel до первого старта, отдельно от volumes.
  Зафиксировать IDs; повторное создание panel требует повторного восстановления
  этих слоёв и новой проверки, не молчаливого продолжения старого receipt.
- **Готово:** mounts/digests/права/оба Fail2ban-каталога проверены, контейнеры
  остановлены; тесты конфликтов имён, неверной платформы, `$PWD`, пересоздания и
  ошибочного запуска. Модели, маршруты, ключи и исходный OAuth не изменяются.
