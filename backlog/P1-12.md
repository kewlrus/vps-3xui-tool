# P1-12 — Certbot activate после cutover и проверка исключения

**Статус:** WAIT P1-08, P1-09, P1-10 (P1-02 DONE-LOCAL 2026-09-23); реальные испытания требуют OPS-02.
**Поток:** активация Certbot.
**Владелец:** `vps3xui/certbot.py`, `tests/unit/test_certbot_activate.py`.

- Реализовать отдельный этап `certbot activate`: target identity, подготовленный
  доверенный комплект, перенос разрешения, рабочий cleanup, корректный домен
  панели, HTTP-01 условия и проверенные hooks обязательны.
- Восстановление ранее разрешённого конкретного guard входит в deployment;
  повторное разрешение на тот же переносимый контракт не изобретать. Оно не
  разрешает запуск произвольных hooks, постоянное открытие TCP/80 или импорт UFW.
- Включать scheduler только после всех gates. Активный timer и отсутствие ошибки
  команды не равны успешному циклу обновления сертификата.
- **Готово:** повтор идемпотентен, чужой machine-id/домен/неработающий cleanup/
  неизвестный hook блокируют включение; active ACME/dry-run выполняется только
  отдельным разрешённым испытанием после cutover, а не из restore verify.
